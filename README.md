# GudangKu

**Inventory Management & Stock Prediction**

GudangKu adalah aplikasi pengelolaan inventori untuk mencatat barang masuk dan barang keluar, memantau stok, serta mengembangkan fitur prediksi stok habis berdasarkan riwayat transaksi.

Project ini dikembangkan secara bertahap sebagai produk terintegrasi untuk tiga mata kuliah.

## Pembagian Mata Kuliah

- **PemWeb:** Pengembangan antarmuka aplikasi web menggunakan React, TypeScript, dan Tailwind CSS.
- **Kriptografi:** Implementasi komponen kriptografi untuk mendukung integritas data transaksi.
- **Keamanan Komputasi dan Siber:** Analisis ancaman, penilaian risiko, dan rancangan kontrol keamanan.

## Struktur Repository

- `PemWeb/` — pekerjaan Pemrograman Web.
- `Kriptografi/` — implementasi dan dokumentasi Kriptografi.
- `security/` — artefak Keamanan Komputasi dan Siber.
- `docs/` — dokumentasi desain produk yang digunakan bersama.

Pengembangan dilakukan secara bertahap mengikuti persyaratan setiap milestone.
