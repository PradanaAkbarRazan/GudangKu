# Keamanan Komputasi dan Siber

Folder ini digunakan untuk artefak keamanan GudangKu.

Tugas 1 berfokus pada threat modeling dan analisis risiko produk, mencakup inventaris aset, diagram arsitektur dan trust boundary, identifikasi ancaman menggunakan STRIDE, lima risiko prioritas, serta rencana kontrol keamanan.

Artefak dan penanda milestone akan disusun sesuai instruksi tugas.
