
# Kebutuhan Fungsional GudangKu

| ID | Kebutuhan Fungsional |
|---|---|
| K-01 | Sistem dapat menampilkan daftar produk beserta informasi stok. |
| K-02 | Sistem dapat menambahkan produk baru ke dalam inventori. |
| K-03 | Sistem dapat menampilkan detail produk berdasarkan ID. |
| K-04 | Sistem dapat memperbarui informasi produk. |
| K-05 | Sistem dapat menghapus produk yang tidak memiliki riwayat stok. |
| K-06 | Sistem dapat menampilkan riwayat pergerakan stok suatu produk. |
| K-07 | Sistem dapat mencatat transaksi barang masuk dan barang keluar. |
